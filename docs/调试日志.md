## 2026-10-04 手机遥控命令映射测试

测试文件：`Test/test_remote_phone.c`

测试范围：手机 CONTROL 状态转换、机械臂关节选择、按钮映射，以及完整数据帧解析到安全遥控命令的处理流程

覆盖内容：

1. 右摇杆 Y 仅作用于选中关节，检查 -512、511 和零输入
2. 上键连续按住三帧只切换一次，松开再按可再次切换
3. 上下切换在 J1 和夹爪之间正确回绕
4. 左右方向键分别输出 turn = +1、-1，中心为零，右摇杆 X 不影响自转
5. A/B 预设映射、A+B 冲突处理，以及 X/Y 夹爪请求
6. S1/S2 对使能和停机标志的映射
7. 非法轴值、方向键和按钮位被拒绝，输出清零，选中关节和方向键历史不变
8. 空指针和非法关节编号被拒绝
9. 使用 srm_build_control 组帧并逐字节输入，先发送 S1=0 完成重新上锁，再发送 S1=1，检查安全输出的全部字段

### 主机测试

在工程根目录 PowerShell 中执行以下脚本
编译或测试失败时抛出错误，不继续运行旧的可执行文件

```powershell
function Invoke-HostLogicTest {
    param(
        [string]$Name,
        [string[]]$Sources
    )

    $testExe = ".\build\$Name.exe"

    & gcc -std=c11 -Wall -Wextra -Wconversion `
        -IApplication -IProtocol -IAlgorithm `
        @Sources -o $testExe -lm

    if ($LASTEXITCODE -ne 0) {
        throw "$Name 编译失败"
    }

    & $testExe

    if ($LASTEXITCODE -ne 0) {
        throw "$Name 测试失败"
    }
}

Invoke-HostLogicTest -Name "test_task_monitor" -Sources @(
    "Test/test_task_monitor.c",
    "Application/task_monitor.c"
)

Invoke-HostLogicTest -Name "test_arm_calib" -Sources @(
    "Test/test_arm_calib.c",
    "Application/arm_calib.c"
)

Invoke-HostLogicTest -Name "test_arm_motion" -Sources @(
    "Test/test_arm_motion.c",
    "Application/arm_motion.c",
    "Application/arm_calib.c",
    "Application/arm_pose.c"
)

Invoke-HostLogicTest -Name "test_mecanum" -Sources @(
    "Test/test_mecanum.c",
    "Algorithm/mecanum.c"
)

Invoke-HostLogicTest -Name "test_remote_input" -Sources @(
    "Test/test_remote_input.c",
    "Application/remote_input.c"
)

Invoke-HostLogicTest -Name "test_remote_phone" -Sources @(
    "Test/test_remote_phone.c",
    "Application/remote_phone.c",
    "Application/remote_input.c",
    "Application/arm_pose.c",
    "Application/arm_calib.c",
    "Protocol/srm_protocol.c"
)
```
