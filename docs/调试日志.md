# 纯软件调试日志

## 2026-10-03 四项主机逻辑测试

测试环境：Windows PowerShell、GCC，均在项目根目录编译并运行。测试程序的输出文件放在被 `.gitignore` 忽略的 `build/` 目录中。本次没有连接 STM32、小车底盘或舵机。

| 测试 | 验证内容 | 结果 |
| --- | --- | --- |
| `test_mecanum` | 麦轮前进、左移、旋转解算，以及无效轮半径时的零输出 | 通过 |
| `test_remote_input` | 遥控状态初始化、选择手机来源、保存有效命令、读取安全命令 | 通过 |
| `test_arm_calib` | 标定表不变量、脉宽插值与四舍五入、反向映射、越界及无穷值裁剪、NaN 和非法参数拒绝 | 通过 |
| `test_arm_motion` | 限速单步移动、精确到达、正反向移动、限位裁剪、已到达保持、原地输出、非法输入失败时不改输出 | 通过 |

### 复现命令

```powershell
gcc -std=c11 -Wall -Wextra -IAlgorithm Test/test_mecanum.c Algorithm/mecanum.c -o build/test_mecanum.exe -lm
.\build\test_mecanum.exe

gcc -std=c11 -Wall -Wextra -IApplication Test/test_remote_input.c Application/remote_input.c -o build/test_remote_input.exe -lm
.\build\test_remote_input.exe

gcc -std=c11 -Wall -Wextra -IApplication Test/test_arm_calib.c Application/arm_calib.c -o build/test_arm_calib.exe -lm
.\build\test_arm_calib.exe

gcc -std=c11 -Wall -Wextra -Wconversion -IApplication Test/test_arm_motion.c Application/arm_motion.c Application/arm_calib.c Application/arm_pose.c -o build/test_arm_motion.exe -lm
.\build\test_arm_motion.exe
```

### 实际结果

四个程序均以退出码 0 正常结束。`test_mecanum`、`test_arm_calib`、`test_arm_motion` 分别打印 `Mecanum tests passed`、`Arm calibration tests passed`、`Arm motion tests passed`；`test_remote_input` 没有打印文字，以退出码 0 表示通过。上述编译命令未输出警告。本次结果说明这些测试覆盖的纯逻辑场景通过，不代表串口无线链路、电机、编码器或舵机已经完成实物验证；本次也未运行 STM32 固件构建。
