# 机械臂代码调用关系

> 按 2026-10-07 的代码整理，初版，后续再改。

## 1. 概况

- 机械臂：J1～J5 五个关节加一个夹爪，共 6 路舵机。
- 控制方式：关节空间控制，只在预设位姿和遥控微调之间切换，没有逆运动学。遥控微调在代码里叫 jog。
- 运行位置：FreeRTOS 的 ArmTask，周期 20 ms。
- 单位：J1～J5 为度，夹爪为 0～1 的比例，0 表示张开，1 表示夹紧。

## 2. 分层结构

从上到下分为五层，数据从输入层一路往下传到舵机。

**输入层**：ProtocolTask 每 5 ms 运行一次，按 USART2 中断、remote_uart、remote_phone、remote_input 的顺序，把手机串口数据变成 `RemoteCommand_t`，再覆盖写入长度为 1 的 `remote_cmd_queue`。机械臂用到的是其中的 `arm` 字段，类型为 `ArmRemoteCommand_t`。

**任务层**：`app_freertos.c` 中的 `StartArmTask`，每 20 ms 运行一次。每个周期先用 `Remote_GetLatest` 读最新命令，再调用 `ArmCycle_Step` 计算，最后用 `ArmServos_Apply` 把脉宽写给舵机。

**周期层**：arm_cycle 负责一个控制周期，依次完成更新目标、限速逼近、换算脉宽三步。

**逻辑层**：\
arm_control 把遥控命令变成目标位姿，处理预设、jog 和夹爪。\
arm_motion 让当前位姿按限速向目标走一步。\
arm_pose 定义位姿结构体，并检查位姿是否在限位内。\
arm_calib 保存标定表，提供限位裁剪、角度到脉宽的换算和每个关节的最大速度。

**驱动层**：servo 把脉宽写成 TIM8、TIM15 的比较值。


## 3. 运行流程

### 3.1 上电初始化

```
MX_FREERTOS_Init
 └─ Servo_InitAll                      绑定舵机对象，不启动 PWM
     └─ Servo_Init                     TIM8 通道 1～4 对应 PC6～PC9，TIM15 通道 1～2 对应 PB14、PB15

StartArmTask
 ├─ ArmCycle_Init                      假定上电时在 STOW，算好 6 路脉宽
 │   ├─ ArmControl_GetPreset           取 STOW 位姿
 │   ├─ ArmControl_Init
 │   ├─ ArmControl_SetTarget           目标设为 STOW
 │   └─ PoseToPulses → ArmCalib_ToPulse
 └─ ArmServos_Start                    先写比较值再开 PWM，第一个脉宽就是 STOW
     └─ Servo_Start
```

### 3.2 每个周期

```
StartArmTask 循环
 ├─ osDelayUntil 等到 20 ms 周期，计算 dt_s
 ├─ Remote_GetLatest                   用 xQueuePeek 读最新命令，超过 30 ms 视为过期，输出全零命令
 ├─ ArmCycle_Step
 │   ├─ dt_s 超过 0.06 s 按 0.06 s 算
 │   ├─ 未使能或请求停机 → ArmControl_SetTarget，目标设为当前位姿，当场停住
 │   │  否则           → ArmControl_Update，由遥控命令算出新目标
 │   ├─ ArmControl_GetTarget
 │   ├─ ArmMotion_Step                 current 向 target 走一步
 │   └─ PoseToPulses → ArmCalib_ToPulse × 6
 ├─ 成功 → ArmServos_Apply → Servo_SetPulseUs × 6
 │  失败 → 不写 PWM，保持上一次脉宽
 └─ TaskMonitor_Beat                   心跳期限 100 ms
```

## 4. 数据结构

| 结构体 / 枚举 | 文件 | 内容 |
| --- | --- | --- |
| `ArmJointIndex_t` | `arm_pose.h` | `ARM_J1`～`ARM_J5`、`ARM_GRIPPER`，`ARM_JOINT_COUNT = 6` |
| `ArmPose_t` | `arm_pose.h` | `float joint[6]`，一组关节角度 |
| `ArmJointCalib_t` | `arm_calib.h` | `min_val`、`max_val`、`pulse_at_min_us`、`pulse_at_max_us`、`max_speed_per_s` |
| `ArmPreset_t` | `remote_input.h` | `ARM_PRESET_NONE`、`ARM_PRESET_GRAB_READY`、`ARM_PRESET_STOW` |
| `ArmRemoteCommand_t` | `remote_input.h` | 范围 -1～1 的 `jog[6]`，`preset`、`gripper_close`、`gripper_open` |
| `RemoteCommand_t` | `remote_input.h` | 底盘的 `forward`、`left`、`turn`，`enabled`、`stop_requested`，以及类型为 `ArmRemoteCommand_t` 的 `arm` |
| `ArmControl_t` | `arm_control.h` | 目标位姿 `target`，是否有目标 `has_target` |
| `ArmCycle_t` | `arm_cycle.h` | `control`，最近一次输出的位姿 `current`，`pulse_us[6]`，`initialized` |
| `Servo_t` | `servo.h` | `htim`、`channel`、`min_pulse_us`、`max_pulse_us` |
| `RemotePhoneArm_t` | `remote_phone.h` | 当前选中的关节 `selected`，上一帧方向键 `last_dpad` |

`ArmCycle_t.current` 是程序认为的当前位置，实际上是上一次输出的值，不是测出来的。

## 5. 各模块函数

### 5.1 servo

文件：`BSP/servo.c`

| 函数 | 作用 |
| --- | --- |
| `Servo_Init` | 检查参数，保存定时器、通道、脉宽范围，不操作硬件 |
| `Servo_Start` | 先用 `Servo_SetPulseUs` 写比较值，再 `HAL_TIM_PWM_Start` |
| `Servo_SetPulseUs` | 脉宽在 min 和 max 之间才写 `__HAL_TIM_SET_COMPARE`，否则拒绝 |
| `Servo_Stop` | `HAL_TIM_PWM_Stop`，目前没有调用 |
| `Servo_SetPosition` | 0～1 比例换算脉宽，目前没有调用 |

前提：定时器预分频 169、周期 19999，1 个计数为 1 µs，PWM 周期 20 ms。

### 5.2 arm_calib

文件：`Application/arm_calib.c`。标定表为 `ARM_CALIB[6]`，每个关节一行。

| 函数 | 作用 | 调用者 |
| --- | --- | --- |
| `ArmCalib_Get` | 按索引取标定项 | pose、motion、control |
| `ArmCalib_Clamp` | 把值裁剪到限位，NaN 返回失败 | motion、control |
| `ArmCalib_ToPulse` | 裁剪 → 线性插值 → 四舍五入成脉宽 | arm_cycle |
| `ArmCalib_ToPulseWithCalib` | 用指定标定项换算，`ToPulse` 内部调用它，测试反向标定也用它 | arm_calib、测试 |
| `ClampWithCalib` | 内部函数，裁剪的具体实现 | arm_calib 内部 |

换算公式：`脉宽 = pulse_at_min + (值 − min) / (max − min) × (pulse_at_max − pulse_at_min)`。`pulse_at_min` 可以大于 `pulse_at_max`，用来处理方向相反的关节。

### 5.3 arm_pose

文件：`Application/arm_pose.c`

| 函数 | 作用 |
| --- | --- |
| `ArmPose_IsValid` | 每个关节都在标定限位内才返回 true，只校验不裁剪 |
| `InRange` | 内部函数，区间判断 |

### 5.4 arm_motion

文件：`Application/arm_motion.c`

| 函数 | 作用 |
| --- | --- |
| `ArmMotion_Step` | 6 个关节各走一步，输出下一步位姿，失败时不修改输出 |
| `StepJoint` | 内部函数，处理单个关节：每步最多走 `max_speed_per_s × dt_s`，剩余距离不足一步就直接到目标 |

### 5.5 arm_control

文件：`Application/arm_control.c`。预设常量为 `PRESET_GRAB_READY` 和 `PRESET_STOW`，数值还要实测。

| 函数 | 作用 |
| --- | --- |
| `ArmControl_Init` | 清零，没有目标 |
| `ArmControl_SetTarget` | `ArmPose_IsValid` 通过才保存目标 |
| `ArmControl_GetTarget` | 读出目标，没有目标返回 false |
| `ArmControl_Clear` | 清除目标，目前没有调用 |
| `ArmControl_GetPreset` | 按编号取预设位姿 |
| `ArmControl_Update` | 由遥控命令算出新目标，见下 |

`ArmControl_Update` 内部顺序：

1. `UpdateInputsValid`：检查指针、`dt_s`、`current`、`jog` 范围。
2. 第一次调用、还没有目标时，用 `ClampPose` 把 current 裁剪后作为初始目标。
3. 有预设请求时调用 `ApplyPreset`，只改 J1～J5，夹爪不变，防止切换姿态时松开已经夹住的矿。没有预设时调用 `ApplyJog`，对 `jog` 不为 0 的关节，以 current 为基准加上 `jog × 最大速度 × dt_s`。
4. `ApplyGripper`：只按夹紧或只按松开时才改夹爪目标，两个都按或都不按就保持。
5. 用 `ArmPose_IsValid` 再检查一次，全部通过才写回 `control`。

几个行为细节：

- 这一帧有预设请求时，jog 被忽略。
- 松开摇杆后 jog 为 0，该关节保持原目标，所以预设动作会继续执行完。
- jog 以 current 而不是旧目标为基准，松手后目标就停在当前位置附近。

### 5.6 arm_cycle

文件：`Application/arm_cycle.c`

| 函数 | 作用 |
| --- | --- |
| `ArmCycle_Init` | current、target、脉宽都设为 STOW |
| `ArmCycle_Step` | 一个控制周期，流程见 3.2；在局部副本里计算，失败时 `cycle` 不变 |
| `PoseToPulses` | 内部函数，6 个关节逐个调用 `ArmCalib_ToPulse` |

### 5.7 任务层

文件：`Core/Src/app_freertos.c`

| 名称 | 作用 |
| --- | --- |
| `servo_1`～`servo_6`、`arm_servos[6]` | 舵机对象，按 J1～J5、夹爪排列，对应关系还要和机械组确认 |
| `arm_cycle` | 机械臂状态，只由 ArmTask 访问 |
| `Servo_InitAll` | 6 次 `Servo_Init`，底层脉宽保护范围为 500～2500 µs |
| `ArmServos_Start` | 6 次 `Servo_Start`，失败进入 `Error_Handler` |
| `ArmServos_Apply` | 6 次 `Servo_SetPulseUs`，某一路被拒绝时该路保持原值 |
| `Remote_GetLatest` | 读 `remote_cmd_queue` 中的最新命令但不取走，过期时输出全零 |
| `StartArmTask` | 初始化，然后每 20 ms 循环一次 |

### 5.8 遥控输入中和机械臂相关的部分

ProtocolTask 每 5 ms 依次调用 `PhoneRemote_Update`、`RemotePhone_ProcessByte`、`RemotePhone_Convert`、`RemoteInput_GetSafe`，最后用 `xQueueOverwrite` 写入 `remote_cmd_queue`。

手机按键映射在 `RemotePhone_Convert` 中：

| 手机输入 | 机械臂命令 |
| --- | --- |
| 按下方向键上或下 | 切换选中关节，J1 → … → 夹爪循环 |
| 右摇杆 Y | 选中关节的 `jog` |
| A | `ARM_PRESET_GRAB_READY` |
| B | `ARM_PRESET_STOW` |
| X / Y | 夹紧 / 松开 |
| 开关 | `enabled`、`stop_requested` |

右摇杆 X 不参与控制。选中夹爪时 jog 不起作用，夹爪只能用 X / Y 控制。

## 6. 安全机制

| 情况 | 处理 | 位置 |
| --- | --- | --- |
| 上电 | 假定在 STOW，先算好脉宽再开 PWM，避免第一个脉宽乱跳；上电前要把机械臂摆到 STOW 附近 | `ArmCycle_Init`、`ArmServos_Start` |
| 遥控超时 200 ms、未使能、急停 | 返回零命令 | `RemoteInput_GetSafe` |
| 命令发布超过 30 ms | 视为过期，返回零命令 | `Remote_GetLatest` |
| 零命令、未使能、停机 | 目标拉回当前位置，当场停住，不卸力 | `ArmCycle_Step` |
| 任务被延迟 | `dt_s` 最多按 0.06 s 算，防止一步跳太远 | `ArmCycle_Step` |
| 目标越界 | 目标进来时校验，jog 和换算时裁剪 | `ArmPose_IsValid`、`ArmCalib_Clamp` |
| 计算失败 | 不写 PWM，保持上一次脉宽 | `StartArmTask` |
| 脉宽超出 500～2500 µs | 驱动拒绝 | `Servo_SetPulseUs` |
| 任务卡死 | 100 ms 内没有心跳，看门狗复位 | `TaskMonitor` |
