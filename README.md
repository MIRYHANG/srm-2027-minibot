# srm-2027-minibot

2027 校内赛小车的 STM32 控制程序，使用 STM32G474VET6、STM32Cube HAL、FreeRTOS 和 CMake，在 CLion 中开发。

## 2026-09-27 开发记录

- 完成遥控输入管理：分别保存手机和手柄命令，支持切换来源；无有效帧、命令超时、未使能或请求停机时，返回零命令。
- 添加遥控输入的电脑端基本测试，覆盖初始化、保存命令和读取命令。
- 将 SRM 遥控协议解析代码加入工程，支持逐字节组帧、CRC 校验及 CONTROL 消息解码。
- 实现 `RemotePhone_Convert()`：检查摇杆原始值，将左摇杆 Y/X、右摇杆 X 转换为前后、左右、旋转命令，并读取 S1 使能和 S2 停机状态。
- 在 CubeMX 中配置 USART2、SPI1、I2C1 和六路舵机 PWM；配置 BMI088 片选及 NRF24L01 的 CSN、CE 引脚。SPI1 时钟已调整为约 5.31 MHz，TIM8 和 TIM15 已调整为 50 Hz。

目前手机遥控命令尚未通过 USART2 接收到 STM32，底盘任务仍使用零速度指令；外设也尚未进行实物联调。
